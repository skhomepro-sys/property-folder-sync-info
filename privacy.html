物件フォルダ同期

プライバシーポリシー

本ポリシーは、社内利用のWindowsアプリ「物件フォルダ同期」によるデータの取り扱いを説明します。

アクセスする情報と利用目的

利用者の承認に基づいてGoogleドライブへ接続します。指定した複製先・変更履歴フォルダーのファイル名、フォルダー構成、更新日時、サイズ、内容照合用の情報およびファイル内容を、同期・変更履歴の保存・整合性確認のために取り扱います。転送前にドライブの空き容量も確認します。

アクセス権限

Googleへの接続には、Driveアカウント全体に及ぶ権限を要求します。プログラムは設定された保存先フォルダーの識別子を確認し、その範囲で同期を行います。Googleドライブ側の内容をサーバーへ書き戻す機能はありません。

保存と共有

サーバーのファイルは指定されたGoogleドライブに保存します。Googleドライブ上のアクセス範囲は、そのアカウント・フォルダーの共有設定に従います。本プログラムには広告配信、外部の利用状況分析サービスへの送信、AIモデルの学習を目的とする機能はありません。

認証情報は実行PC内に保存し、セットアップ時にWindowsのアクセス制限を設定します。Googleのパスワード自体を本プログラムが保存することはありません。ファイル名・パス・エラー情報を含む処理ログはPC内に保存します。

保存期間と削除

複製・変更履歴・処理ログは自動的な保存期限を設けず、運用担当者が管理します。利用者はGoogleアカウントの接続済みアプリ管理画面でアクセスを取り消せます。アクセスを取り消すと同期は停止しますが、保存済みのファイルやログは削除されません。保存済みデータの削除は運用担当者へご依頼ください。

Googleユーザーデータ

Google APIから取得した情報の利用および他のアプリへの転送は、制限付き使用の要件を含むGoogle API Services User Data Policyに従います。

お問い合わせ・変更

お問い合わせは、社内の本アプリ運用担当者へご連絡ください。データの取り扱いを変更する場合は、本ページの説明を更新します。
